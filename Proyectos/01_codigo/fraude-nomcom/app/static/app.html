🔎 Consulta individual (este frontend)

Escribe un nombre comercial en el buscador y presiona Evaluar. El sistema lo comparará contra la lista de referencia usando 4 capas de detección: normalización de leetspeak (ej: p3p1t0→PEPITO), similitud sintáctica, semántica y evaluación con IA.

⚡ Procesamiento masivo (API batch)

Para activar el análisis de todas las afiliaciones pendientes en BigQuery, consumir el siguiente endpoint:

POST {BASE_URL}/match/batch Content-Type: application/json X-Origin: PIPELINE_HUGO X-User: tu-email@izipay.pe { "source": "bigquery", "use_ia": true, "days_lookback": 3 }

Esto lee las afiliaciones de los últimos N días de la tabla de input, ejecuta el matching completo, y guarda todos los resultados en BigQuery automáticamente.

📊 Tablas BigQuery donde se guardan los resultados

Cada consulta (individual o batch) queda registrada en BigQuery para análisis posterior:

-- Resultados del matching (scores, alertas, detalle IA) SELECT * FROM `dev-izipay-data-storage.master_party.resultado_analisis_nomcom` WHERE fecha_analisis >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 1 DAY) ORDER BY score_final DESC; -- Log de consultas (trazabilidad) SELECT * FROM `dev-izipay-data-storage.master_party.log_consultas_nomcom` ORDER BY fecha_consulta DESC LIMIT 50;
